# Get file status for a dataset

This returns a formatted status string for
[`show_record`](https://imperialcollegelondon.github.io/safedata/dev/reference/show_concepts.md)
and
[`show_worksheet`](https://imperialcollegelondon.github.io/safedata/dev/reference/show_concepts.md)
showing if a dataset is available globally or locally as a private copy.

## Usage

``` r
file_status(metadata)
```

## Arguments

- metadata:

  A loaded metadata dictionary for a record
