# Adds location data to a SAFE data worksheet.

This function adds location data to the rows of a safedata worksheet,
converting it into a
[`sf`](https://r-spatial.github.io/sf/reference/sf.html) spatial
features object. Rows are matched to values in a location_field: if
there is only one location field, it will be used automatically;
otherwise, the specific field must be provided.

## Usage

``` r
add_locations(
  obj,
  location_field = NULL,
  location_table = NULL,
  gazetteer_info = FALSE
)
```

## Arguments

- obj:

  An existing object of class `safedata`

- location_field:

  The name of a location field in a `safedata` object.

- location_table:

  An existing location table for a dataset, as generated by
  [`get_locations`](https://imperialcollegelondon.github.io/safedata/dev/reference/get_locations.md).

- gazetteer_info:

  Should all the gazetteer fields be included in the returned
  [`sf`](https://r-spatial.github.io/sf/reference/sf.html) object. See
  [`load_gazetteer`](https://imperialcollegelondon.github.io/safedata/dev/reference/load_gazetteer.md)
  for details.

## Value

A modified `safedata` object including geometry data.

## See also

[`get_locations`](https://imperialcollegelondon.github.io/safedata/dev/reference/get_locations.md),
[`load_gazetteer`](https://imperialcollegelondon.github.io/safedata/dev/reference/load_gazetteer.md),
[`load_location_aliases`](https://imperialcollegelondon.github.io/safedata/dev/reference/load_location_aliases.md)

## Examples

``` r
   set_example_safedata_dir()
   beetle_abund <- load_safe_data(1400562, "Ant-Psel")
   beetle_abund <- add_locations(beetle_abund)
   set_example_safedata_dir(on=FALSE)
```
